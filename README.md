# Website starter template

Minimal **Next.js + TypeScript** skeleton for customer sites generated by the builder.

Push this folder to a **GitHub repository** with **Template repository** enabled, then set `TEMPLATE_REPO_URL` in the builder app.

## Included

| Piece | Location |
| --- | --- |
| Next.js App Router + TypeScript | `app/`, `tsconfig.json` |
| Run / build scripts | `package.json` |
| Vercel defaults | `vercel.json` |
| Root layout + Inter font | `app/layout.tsx` |
| Global reset + CSS variables | `app/globals.css` |
| Placeholder home page | `app/page.tsx` |
| Agent instructions | `AGENTS.md` |
| Cursor Cloud environment | `.cursor/environment.json` |

Customer design and copy come from the builder chat, not from this template.

## Local check

```bash
npm install
npm run build
```

Connect the generated repo to **Vercel** with production branch `main`.
